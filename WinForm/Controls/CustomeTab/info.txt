اگر علاوه بر عنوان، برای هر تب یک شناسه ثابت نیاز دارید، بهتر است یک مدل تعریف کنید:

csharp
public class TabDefinition
{
    public string Id { get; set; } = string.Empty;
    public string Title { get; set; } = string.Empty;
}
و این overload را نیز به CustomTab اضافه کنید:

csharp
public void SetTabs(IEnumerable<TabDefinition>? tabDefinitions)
{
    ClearTabs();

    if (tabDefinitions == null)
        return;

    foreach (TabDefinition definition in tabDefinitions
                 .Where(x => x != null && !string.IsNullOrWhiteSpace(x.Title)))
    {
        AddNewTab(definition.Title.Trim(), definition.Id);
    }

    if (items.Count > 0)
        SelectTab(items[0]);
}
